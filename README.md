# Todo exercise – parts 1–8

This project contains a complete implementation of the Oamk Todo exercise series.

## Implemented parts

1. React frontend with add/delete in local state
2. Node.js + Express + PostgreSQL backend
3. Mocha + Chai REST API tests
4. React calls the REST API with Axios
5. Environment variables, routing and backend middleware
6. Backend authentication and authorization with bcrypt + JWT
7. Frontend sign-up/sign-in, React Router, Context and protected routes
8. MVC-style backend for tasks + ApiError class


## Requirements

- Node.js 24.x LTS
- PostgreSQL
- pgAdmin 4
- Visual Studio Code

## PostgreSQL databases

Create two databases in pgAdmin:

- `todo`
- `test_todo`
